# Practice 02: Python Control Flow Basics

This practice covers Python control flow topics including:
- Boolean Values & Operators
- Conditional Statements (`if`, `if-else`, `if-elif-else`, short-hand)
- Loops (`while`, `for`, `break`, `continue`)

## Project Structure
- `boolean/`: Boolean values, comparisons, and logical operators.
- `if_else/`: Decision making with conditional statements.
- `loops/`: Iteration using while and for loops with break/continue control.
